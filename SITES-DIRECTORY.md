### Dashboard Features
- **Direct All (427):** View and search all 427 companies in 1 click.
- **WhatsApp:** 1-click status cycle & instant chat links.
- **Pipeline:** New • Contacted • Interested • In Process • Not Decided • Paid • Rejected.
- **Website Changes:** Track custom edits & notes per company.
- **Archive:** Hide rows with confirmation popup; restore anytime.
- **Export:** Instant CSV / JSON backups.
