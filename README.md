## ⚡ Deploying Individual Websites to Vercel

To deploy any of the 100 websites as an independent Vercel project:

1. **Via Vercel Web Dashboard:**
   - Import this GitHub repository (`knowledgeispowerbyrahul-hub/uae-car-rentals`).
   - In **Project Settings** → **Root Directory**, select the website folder (e.g., `./qas-dubai-car-rental`).
   - Set project name to a short slug (e.g., `qas-rent`).
   - Click **Deploy**.

2. **Via Vercel CLI:**
   ```bash
   cd <site-folder>
   vercel deploy --prod --yes --name <short-name>
   ```
